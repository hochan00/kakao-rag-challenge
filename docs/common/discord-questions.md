# 디스코드 공지 및 수강생 질문 정리

디스코드에 공유된 안내와 수강생 질문을 주제별로 기록합니다. 각 질문은 원문 질문·답변·핵심 의미의 3행으로 관리합니다.

## RAG 약관 데이터 준비

| 구분 | 내용 |
| --- | --- |
| 질문 | RAG 시스템을 구축하려면 약관 데이터를 저장한 뒤 런타임에서 외부 저장소의 약관 문서 파일을 불러와야 하는 것으로 알고 있는데, 구글 드라이브 마운트가 불가하다면 Retrieval용 약관 데이터를 어떤 방식으로 Colab 런타임에 가져와야 하나요? |
| 답변 | Retrieval에 사용할 약관 데이터를 Colab 런타임에 준비하는 방식은 팀별로 자유롭게 구현하면 되며, 공개 원문 출처에서 실행 중 자동으로 가져오거나, 필요한 데이터를 결과기 Colab 코드에 포함하거나, 실행 중 생성·가공해 메모리 또는 Colab 임시 공간에 저장할 수 있습니다. 단, 새 Colab 런타임에서 결과기 Colab을 위에서 아래로 한 번 실행했을 때 데이터 준비부터 검색·답변 생성까지 모두 동작해야 합니다. |
| 핵심 의미 | 외부 드라이브를 미리 마운트해 둔 상태에 의존할 수 없으므로, 노트북 자체가 새 런타임에서도 필요한 약관 데이터를 스스로 확보·준비하고 RAG 전체 과정을 재현할 수 있게 만들면 됩니다. |
