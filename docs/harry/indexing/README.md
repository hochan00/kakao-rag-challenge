## 핵심 결정 요약

| 항목 | 결정 | 한 줄 근거 |
| --- | --- | --- |
| 파싱 | 정규식, 문서별 항 마커 분기 (`①` 3종 / `N.` 통합약관) | 같은 `N.`이 문서에 따라 항 또는 호 |
| 청킹 | 항(unit) 229개 임베딩 → 조(article) 72개로 max 집계 | 인용 계약이 `[문서명, 조번호]`, 조 최대 3,482자 |
| 임베딩 | bge-m3 vs e5-base를 공개 10문항 실측으로 확정 (계획 Task 5 결정 규칙) | 벤치마크가 아니라 이 코퍼스의 Recall로 결정 |
| 저장 | 벡터 DB 없음. numpy 전수 cosine + TF-IDF char n-gram | 229 벡터 = 0.94MB, ANN은 손해만 |
